# Тестовое задание 

## Структура проекта
- feed_task.py - основной модуль
- data_processing.py - модуль со вспомогательными функциями для
обработки данных
- tests.py - автотесты
- django_view_example.py - пример подключения исправленной функции в django View
- docs/output.xml - результат работы программы

## Что сделано
### Переработка build_yml
1. Переписан алгоритм на основе конкатенации строк. Теперь xml формируется через xml.etree.ElementTree
2. Функция для фильтрации данных filter_data (строка 114) - фильтрует данные (продукты и категории)
в соответствии с требованиями ТЗ
3. функция filter_product - логика фильтрации продуктов (вызывается из функции filter_data)
4. функция check_price - валидация старой цены
5. уникальность категорий - строка 127, заполнение уникальных категорий на основе отбора ключа category_id из
отфильтрованого списка products

### Автотесты
в файле tests.py реализована базовая проверка на соответсвие требованиям ТЗ
